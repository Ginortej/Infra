# Program_Server — прототип интерфейса

Минималистичный интерфейс в стиле Obsidian для будущего приложения на Go + Wails.
Сейчас это чистый HTML/CSS/JS без сборки и без бэкенда: данные тестовые (`frontend/data.js`).

## Как открыть
Дважды кликни `frontend/index.html`, он откроется в браузере.

## Что есть
- Лента модулей слева: Серверы · VPN · Лабы · Скрипты
- Боковая панель с фильтром, группами и статусами
- Вкладки: SSH-терминал, локальный терминал, YAML-редактор с подсветкой, SFTP (две панели), обзор лабы с планом
- Палитра команд: `Ctrl+P`
- Горячие клавиши: `Ctrl+T` новый терминал, `Ctrl+W` закрыть вкладку, `Ctrl+Tab` следующая вкладка, `Ctrl+S` в редакторе
- У каждой вкладки терминала свой выбор VPN (чип справа сверху)
- Статус-бар: активные VPN, запущенные VM, фоновые задачи с прогрессом

## Файлы
- `frontend/index.html` — каркас окна
- `frontend/styles.css` — тема (цвета в `:root`)
- `frontend/data.js` — тестовые данные, потом их заменят вызовы Go
- `frontend/app.js` — логика интерфейса

## Дальше (перенос в Wails)
1. `wails init -n infra -t svelte-ts`
2. Разнести блоки из `app.js` по Svelte-компонентам: Sidebar, TabBar, Terminal, Editor, Sftp, Lab, Palette, StatusBar
3. Терминал заменить на xterm.js, редактор на CodeMirror 6
4. `data.js` заменить вызовами Go-сервисов через Wails bindings
